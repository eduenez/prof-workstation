dalekanium — clean Windows 11 install: walk-through

Full plan: M:\Eduardo\repos\prof-workstation\windows\dalekanium\PLAN.md · Board: ASUS ROG STRIX B450-F · Del = firmware setup · F8 = boot menu

0. Before powering off

  • Pre-wipe backup done: F:\dalekanium-prewipe + system image F:\WindowsImageBackup
  • Both repos committed and pushed
  • Rufus stick made from the 26H2 ISO: GPT, UEFI (non CSM). Ticked: no MS-account requirement, local account Eduardo, skip privacy questions, no BitLocker auto-encryption. Unticked: TPM/Secure Boot bypass, "Windows CA 2023 bootloaders", "SkuSiPolicy.p7b"
  • wincmd.key saved in Bitwarden
  • At hand: Bitwarden master password + 2FA device; GitHub 2FA; UTSA login + MFA phone

1. Firmware (press Del at power-on)

  1. F7 for Advanced Mode if needed.
  2. Advanced → AMD fTPM configuration → Firmware TPM.
  3. Boot → CSM → Launch CSM: Disabled.
  4. Boot → Secure Boot → OS Type: Windows UEFI mode.
  5. F10 save & exit, then power off.
  6. Do not update the BIOS.

2. Cables (power off, PSU switch off)

  1. Unplug the SATA cable of the M: SSD (Crucial MX500 500 GB). It holds the old boot partition and all your data.
  2. Unplug both USB drives: F: WD Elements 13 TB, E: WD easystore 4 TB.
  3. Leave only the NVMe (C:, Silicon Power 512 GB) and the Rufus stick.

3. Install

  1. Power on, F8, choose "UEFI: <USB stick>".
  2. Language/keyboard: English (US). "Install Windows 11". "I don't have a product key".
  3. Edition: Windows 11 Pro (matches your licence).
  4. Custom install. Delete every partition on the one disk (~477 GB) → select the unallocated space → Next.
STOP if setup lists more than one disk: M: is still connected. Power off and unplug it.

4. First setup screens

  1. Region US; keyboard US, add US-International.
  2. Network: wired cable is fine.
  3. Local account Eduardo: set the password (+ security questions).
  4. Every privacy toggle off. Decline every offer: Phone Link, OneDrive backup ("skip"/"don't back up"), Office/Game Pass trials.

5. Reconnect and check

  1. Shut down. Reconnect the M: SSD and both USB drives. Boot.
  2. Win+X → Disk Management. Letters must be M: MEDIA, F: Elements, E: easystore. Fix with "Change Drive Letter". Leave the old 1 GB "System Reserved" partition on the M: disk alone.
  3. Settings → System → Activation: Active (digital licence).

6. Back to git (in cmd)

  1. winget install -e --id Git.Git --scope machine
  2. winget install -e --id Bitwarden.Bitwarden --scope machine. Log in; Settings → enable SSH agent.
  3. services.msc → "OpenSSH Authentication Agent" → Startup type Disabled.
  4. setx HOME M:\Eduardo, then open a new cmd window.
  5. ssh -T git@github.com: approve in Bitwarden; expect "Hi eduenez!".
  6. cd /d M:\Eduardo\repos\prof-workstation && git pull
Then: install the Claude desktop app, link this computer, connect M:\Eduardo\repos, and say: "dalekanium is reinstalled; continue with PLAN.md, Phase 5." Don't install the sync apps until then (old folders get renamed first).

If something goes wrong

  • Stick not in the F8 menu: CSM is off, so only UEFI sticks show. Remake the stick with GPT/UEFI.
  • "Secure Boot violation": set Secure Boot → Disabled, install, turn it back on later.
  • "This PC can't run Windows 11": fTPM isn't enabled (step 1.2).
  • Microsoft account demanded anyway: unplug the network cable at that screen. If there's still no local option, stop and ask Claude from another device.
  • Escape hatch: the old system image is on F:. Nothing is encrypted, so all disks stay readable from any computer.
